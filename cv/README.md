# CV

**[`Thea_Arcadia_CV_full.md`](Thea_Arcadia_CV_full.md) is the source of truth.** It's the complete record: every job, project, number and date. Nothing is cut from it.

Everything else is made from it:

| File | What it is |
|---|---|
| [`Thea_Arcadia_CV_full.md`](Thea_Arcadia_CV_full.md) | The full CV. Edit this first. |
| [`Thea_Arcadia_Resume.md`](Thea_Arcadia_Resume.md) | The one-page resume, as Markdown. |
| [`one-page/resume.template.html`](one-page/resume.template.html) | The one-page resume's layout. |
| [`one-page/build.js`](one-page/build.js) | Builds the one-page PDF from the template. |
| [`../Thea_Arcadia_Resume.pdf`](../Thea_Arcadia_Resume.pdf) | The built one-page PDF, linked from my profile. |

## Rules

1. **Change the full CV first.** The one-page resume and the website only use facts that are in the full CV. To change a fact, edit the full CV, then bring the one-pager in line.
2. **The one-pager is a selection, not a rewrite.** It can shorten and merge lines, but it never adds facts the full CV doesn't have.
3. **No phone number in this repo.** `build.js` adds one only when `PHONE` is set, for the copy sent with applications.
